<h1>О проекте</h1>
  <p>Этот проект представляет собой веб-сокет клиент для обработки событий подарков пользователей на платформе Twitch. Основные функции:</p>

<p>Поддержка двух специфических подарков:</p>
<p>"Перевернуть экран" - выполняет операцию инвертирования экрана</p>
<p>"Отключить клавиатуру/мышь" - блокирует ввод пользователя</p>
